## Скрапинг геоданных, преобразование в H3 индексы и формирование справочника

### 1. Скрапинг данных о городах России
Скрипт ```scrapper.py``` собирает GeoJSON файлы о городах с сайта ```https://tools.paintmaps.com```
и кладёт их в папку ```geojsons_scrapped```

### 2. Конвертация GeoJSON в H3-индексы
Скрипт ```coord2geohash.py``` проходится по всем файлам в папке ```geojsons_scrapped``` 
и преобразует координаты городов в H3-индексы N-го разрешения. N передаётся как аргумент
при запуске скрипта. H3-индексы записываются в колонку geohash в новом файле csv, который
находится в папке ```coord2hash_csv```.
Пример для города Адыгейск: после запуска скрипта в папке coord2geohash_csv появился файл

### 3. Нахождение городов с населенем больше 100 тысяч человек
В файле `городаКоординаты.csv` записаны города с населением больше 100 тысяч человек
и одна координата этого города. Скрипт `big_city.py` преобразует координату в H3-индекс. 
Потом проходится по файлам в папке `coord2geohash_csv` и ищет файл, в котором есть полученный H3-индекс.
Этот файл добавляется в папку `final_csv_dir`

### 4. Формирование справочника
Скрипт `main.py` создаёт папку `final_regions_csv` в которую кладёт csv файлы с данными о городе.
Пример:
```
0,19,Республика Хакасия,,Khakassia,8825260c09fffff,ABAKAN,АБАКАН
где row_number, - уникальный индекс строки 
region_code, - код региона по ГИБДД 
region_name, - название региона РУС 
district_id, - пусто 
district_name, - сокращенное название региона ENG 
geohash, - h3index 
event_city, - город РУС 
travel_city – город ENG
```

### 5. Аэропорты Москвы
Добавлены GeoJSON файлы аэропортов Москвы в папку `airport_geojson`
Скрипт `airports.py` преобразует GeoJSON файлы в H3-индексы и добавляет в общий справочник.
### 6. Объединение справочника в один файл
Скрипт `result_union.py` объединяет csv файлы из папки `final_regions_csv` в один `result_union_file.py`
